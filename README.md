Google Maps Platform offers APIs and SDKs for maps, routes, and places functionality.

**Areas:** Environment · Geocoding · Geolocation · Maps · Navigation · Places · Routing · Solar · Geospatial

## Google Maps Platform on APIs.io

Everything profiled for Google Maps Platform is published on APIs.io rather than in this repository. Start at the provider page — **[apis.io/providers/google-maps/](https://apis.io/providers/google-maps/)** — or go straight to one of the APIs or properties below.

### APIs (41)

- [Maps SDK for Android](https://apis.io/apis/google-maps/maps-sdk-for-android/) — Add maps to Android and Wear OS applications with customizable markers, polylines, and user interaction support.
- [Maps SDK for iOS](https://apis.io/apis/google-maps/maps-sdk-for-ios/) — Add maps to iOS applications with automatic server access, map display, and gesture handling.
- [Google Maps for Flutter](https://apis.io/apis/google-maps/google-maps-for-flutter/) — Add Google Maps to Flutter applications across Android, iOS, and web platforms.
- [Navigation SDK for Android](https://apis.io/apis/google-maps/navigation-sdk-for-android/) — Integrate Google Maps turn-by-turn navigation into Android applications with UI customization and route configuration.
- [Navigation SDK for iOS](https://apis.io/apis/google-maps/navigation-sdk-for-ios/) — Integrate Google Maps turn-by-turn navigation into iOS applications with UI customization and route configuration.
- [Navigation for Flutter and React Native](https://apis.io/apis/google-maps/navigation-for-flutter-and-react-native/) — Add Google Maps turn-by-turn navigation to cross-platform Flutter and React Native applications.
- [Places API](https://apis.io/apis/google-maps/places-api/) — Access information about places using HTTP requests including search, details, and autocomplete.
- [Places SDK for Android](https://apis.io/apis/google-maps/places-sdk-for-android/) — Access rich place information including names, addresses, ratings, and photos in Android applications.
- [Places SDK for iOS](https://apis.io/apis/google-maps/places-sdk-for-ios/) — Access rich place information including names, addresses, ratings, and photos in iOS applications.
- [Distance Matrix API](https://apis.io/apis/google-maps/distance-matrix-api/) — Calculate travel distance and time for multiple origins and destinations.
- [Roads API](https://apis.io/apis/google-maps/roads-api/) — Snap GPS coordinates to roads and find speed limits.
- [Routes API](https://apis.io/apis/google-maps/routes-api/) — Compute routes and route matrices with real-time traffic, replacing Directions and Distance Matrix APIs.
- [Route Optimization API](https://apis.io/apis/google-maps/route-optimization-api/) — Assign tasks and routes to a vehicle fleet, optimizing against objectives and constraints for transportation goals.
- [Maps Static API](https://apis.io/apis/google-maps/maps-static-api/) — Embed a Google Maps image on a web page using a simple HTTP request with no JavaScript required.
- [Maps Embed API](https://apis.io/apis/google-maps/maps-embed-api/) — Place an interactive map or Street View panorama on a web page with a simple HTTP request and no JavaScript required.
- [Street View Static API](https://apis.io/apis/google-maps/street-view-static-api/) — Embed a non-interactive Street View panorama or thumbnail into a web page using a simple HTTP request.
- [Maps URLs](https://apis.io/apis/google-maps/maps-urls/) — Launch Google Maps and initiate actions like search, directions, or map display using cross-platform URL schemes.
- [Elevation API](https://apis.io/apis/google-maps/elevation-api/) — Return elevation data for locations on the earth or sampled elevation data along paths.
- [Geolocation API](https://apis.io/apis/google-maps/geolocation-api/) — Determine device location using cell tower and Wi-Fi access point data.
- [Time Zone API](https://apis.io/apis/google-maps/time-zone-api/) — Retrieve time zone information for coordinates on the earth including UTC offset and daylight savings data.
- [Address Validation API](https://apis.io/apis/google-maps/address-validation-api/) — Validate and standardize addresses, returning deliverability verdicts, geocodes, and address component details.
- [Aerial View API](https://apis.io/apis/google-maps/aerial-view-api/) — Create and display photorealistic 3D aerial view videos rendered using Google geospatial imagery.
- [Map Tiles API](https://apis.io/apis/google-maps/map-tiles-api/) — Provide high-resolution Photorealistic 3D Tiles, 2D Tiles, and Street View Tiles for immersive map visualizations.
- [Maps Datasets API](https://apis.io/apis/google-maps/maps-datasets-api/) — Upload, manage, and serve custom geospatial datasets for use with Google Maps Platform.
- [Places Aggregate API](https://apis.io/apis/google-maps/places-aggregate-api/) — Compute statistical insights and aggregate data about places within a specified area.
- [Places Insights](https://apis.io/apis/google-maps/places-insights/) — Query places data in BigQuery to derive statistical insights for site selection, market analysis, and business intelligence.
- [Air Quality API](https://apis.io/apis/google-maps/air-quality-api/) — Request air quality data for a specific location including air quality indexes, pollutants, and health recommendations.
- [Pollen API](https://apis.io/apis/google-maps/pollen-api/) — Deliver location-specific pollen data including pollen types, plant species, pollen index, and health recommendations.
- [Solar API](https://apis.io/apis/google-maps/solar-api/) — Access solar potential data for hundreds of millions of buildings worldwide including building insights and data layers.
- [Weather API](https://apis.io/apis/google-maps/weather-api/) — Provide comprehensive weather information including temperature, precipitation, wind, cloud cover, and forecasts for locations worldwide.
- [Street View Insights](https://apis.io/apis/google-maps/street-view-insights/) — Analyze Google Street View imagery data to derive insights about the location and condition of public assets.
- [Imagery Insights API](https://apis.io/apis/google-maps/imagery-insights-api/) — Query and classify street-level imagery to extract actionable intelligence from real-world visual observations.
- [Roads Management Insights](https://apis.io/apis/google-maps/roads-management-insights/) — Analyze route-based trip duration and speed data for managing road networks and transportation infrastructure.
- [Google Earth](https://apis.io/apis/google-maps/google-earth/) — Access Google Earth geospatial data and imagery analysis capabilities for developers.
- [Google Maps Platform Autocomplete API](https://apis.io/apis/google-maps/google-maps-autocomplete-api/) — Get place predictions based on text input
- [Google Maps Platform Directions API](https://apis.io/apis/google-maps/google-maps-directions-api/) — Route computation between origin and destination
- [Google Maps Platform Geocoding API](https://apis.io/apis/google-maps/google-maps-geocoding-api/) — Forward and reverse geocoding operations
- [Google Maps Platform Nearby Search API](https://apis.io/apis/google-maps/google-maps-nearby-search-api/) — Search for places near a specific location
- [Google Maps Platform Photos API](https://apis.io/apis/google-maps/google-maps-photos-api/) — Access photos associated with places
- [Google Maps Platform Place Details API](https://apis.io/apis/google-maps/google-maps-place-details-api/) — Get detailed information about a specific place
- [Google Maps Platform Text Search API](https://apis.io/apis/google-maps/google-maps-text-search-api/) — Search for places using a text query

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Google Maps Platform: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
