# Google Maps Platform

> Google Maps Platform offers APIs and SDKs for maps, routes, and places functionality — geospatial services spanning maps, geocoding, routing, places, imagery, and environment data. Authentication is by API key (some Cloud services also accept OAuth 2.0). This file was generated by API Evangelist from the catalog for this provider; no provider-published llms.txt was found (developers.google.com/llms.txt returns 404).

## APIs
- [Maps JavaScript API](https://developers.google.com/maps/documentation/javascript): Embed customizable maps in web pages.
- [Geocoding API](https://developers.google.com/maps/documentation/geocoding): Convert addresses to coordinates and back.
- [Places API (New)](https://developers.google.com/maps/documentation/places/web-service/op-overview): Search, details, autocomplete, and photos for places.
- [Directions API](https://developers.google.com/maps/documentation/directions): Directions for driving, walking, cycling, transit.
- [Distance Matrix API](https://developers.google.com/maps/documentation/distance-matrix): Travel distance/time for many origins and destinations.
- [Routes API](https://developers.google.com/maps/documentation/routes): Routes and route matrices with real-time traffic (supersedes Directions + Distance Matrix).
- [Route Optimization API](https://developers.google.com/maps/documentation/route-optimization): Fleet task and route assignment.
- [Roads API](https://developers.google.com/maps/documentation/roads): Snap GPS to roads, speed limits.
- [Address Validation API](https://developers.google.com/maps/documentation/address-validation): Validate and standardize addresses.
- [Elevation API](https://developers.google.com/maps/documentation/elevation): Elevation data for locations and paths.
- [Geolocation API](https://developers.google.com/maps/documentation/geolocation): Device location from cell towers and Wi-Fi.
- [Time Zone API](https://developers.google.com/maps/documentation/timezone): Time zone for coordinates.
- [Maps Static API](https://developers.google.com/maps/documentation/maps-static): Map images via HTTP.
- [Maps Embed API](https://developers.google.com/maps/documentation/embed): Embed maps/Street View via iframe.
- [Street View Static API](https://developers.google.com/maps/documentation/streetview): Street View panoramas and thumbnails.
- [Map Tiles API](https://developers.google.com/maps/documentation/tile): 2D, Street View, and photorealistic 3D tiles.
- [Aerial View API](https://developers.google.com/maps/documentation/aerial-view): Photorealistic 3D aerial view videos.
- [Maps Datasets API](https://developers.google.com/maps/documentation/datasets): Upload and serve custom geospatial datasets.
- [Places Aggregate API](https://developers.google.com/maps/documentation/places-aggregate): Aggregate statistics about places in an area.
- [Air Quality API](https://developers.google.com/maps/documentation/air-quality): Air quality indexes, pollutants, health recommendations.
- [Pollen API](https://developers.google.com/maps/documentation/pollen): Pollen types, indexes, and health recommendations.
- [Solar API](https://developers.google.com/maps/documentation/solar): Solar potential and data layers for buildings.
- [Weather API](https://developers.google.com/maps/documentation/weather): Temperature, precipitation, wind, and forecasts.
